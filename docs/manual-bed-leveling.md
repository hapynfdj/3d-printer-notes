# 手动调平（无探针·床升降 Z 机型）

适用于没有探针/BLTouch/bed mesh，且 Z 轴是床升降结构的机器：**Z=0 是打印位**（喷嘴离床最近），归零把床降到 Z 最大值（本机 151.25）。

普通教程都假设 Z=0 是归零位，照着做会把喷嘴怼进床里。这台机器必须用下面的安全流程。

## 安全规则（本机型）

- **永远不要归零后直接 `G1 Z0`**。归零后床在 Z=151.25，一次长距离下降可能撞上残留物或高点。必须分步下：Z5 → Z2 → Z1 → Z0.5 → Z0.1。
- 每次换角之前，**先抬 Z 到 ≥2**，再移动 XY，再分步下降。
- `G28`（全部归零）会把床放到 Z=151.25——每次调角前都从这里开始，最安全。

## 调平前的准备

1. 清理喷嘴尖端残留——残留耗材会垫高纸张，读数全是假的。
2. 擦干净玻璃**正面和背面**，确认玻璃下面没有异物（一粒碎屑就能让一个角永久偏高）。
3. 检查玻璃夹是否受力均匀——夹子压力不均会把玻璃压弯。
4. 冷床先过一遍没问题，正式打印 PETG 前要在 75 °C 热床再复查一遍（热膨胀会改变平面）。

## 纸感判断（基准）

A4 纸放在喷嘴下，Z 在 0，轻拉：

- **太紧**——纸进不去或被夹死 → 该角床偏高
- **正常**——能顺利滑入，有均匀明确的阻尼感；拉的时候有阻力但不打皱，既不松也不紧 ← 目标
- **太松**——完全没接触 → 该角床偏低

## 螺丝方向

**永远先试 1/8 圈，再判断方向**，别凭感觉：

- 纸变紧 → 床向喷嘴方向移动（拧紧方向）
- 纸变松 → 床远离喷嘴（拧松方向）

确认一次方向后一直用这个方向。到第三轮时，每次调整应该不超过 1/16 圈。

## 顺序（本机 190×190 坐标）

1. `G28`。到前左角 **X20 Y20**（先抬 Z → 移动 → 分步下降）。以这个角为基准"正常"手感。
2. 前右角 **X170 Y20**——调它的螺丝直到手感一致。
3. 后右角 **X170 Y170**。
4. 后左角 **X20 Y170**。
5. 中心 **X95 Y95**——只检查，不要用角螺丝去追中心。

四个角是相互影响的：完整走完一轮后，第一个角会漂移。**至少循环 3 轮**，直到每个角都稳定在 1/16 圈以内的微调。

## 中心和角的关系

- 中心与角手感一致 → 调平完成
- 中心明显偏松 → 玻璃/床中间塌陷
- 中心明显偏紧 → 玻璃/床中间隆起

如果中心与角的差距超过一张纸的厚度，**不要用角螺丝补偿**。重新铺玻璃、检查玻璃下异物、或翻面再试。

## 关于纸感的精度

纸感只是定性比较。说"稍紧"或"纸能卡住"就够了，除非用已知厚度的塞尺或受控 Z 步进测量，否则**不要**把"纸能卡住"换算成一个编造的 0.03–0.05 mm 数值。

## 热床复查

冷床流程走完后：热床加热到 75 °C，等 5 分钟热稳定，再完整跑一遍角和中心。PETG 的实际打印平面是**热**平面。

## 下一层首层成功的标准

- 线条轻微压扁、与相邻线融合、光泽均匀
- 圆/珠状线且有间隙、一拉就掉 → 喷嘴仍然太高
- 透明薄膜/脊线/刮擦声 → 喷嘴太低
- 指甲能抠起来的第一层 = 没修好
