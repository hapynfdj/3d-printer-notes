# 手动调平（无探针·床升降 Z 机型）

适用于无探针（BLTouch / bed mesh / screws_tilt）且 Z 轴为床升降结构的机型。本机 Z=0 为打印位（喷嘴距床最近），归零后床位于 Z=151.25。

常规调平教程假设 Z=0 为归零位，直接套用会导致喷嘴撞击床面。本机型须遵循以下流程。

## 安全规则

- 归零后禁止直接执行 `G1 Z0`。床位于 Z=151.25，长距离下降可能碰撞残留物或高点。须分步下降：Z5 → Z2 → Z1 → Z0.5 → Z0.1。
- 每次更换调平角位前，先抬升 Z 至 ≥2，再移动 XY，然后分步下降。
- `G28` 归零后床位于 Z=151.25，是每次角位操作的起始状态。

## 调平前检查

1. 清理喷嘴尖端残留：残留耗材会垫高塞尺，导致读数失真。
2. 擦拭玻璃两面，确认玻璃下方无碎屑（异物会导致单角永久偏高）。
3. 检查玻璃夹压力是否均匀：夹力不均会压弯玻璃平面。
4. 冷床调平通过后，PETG 打印前须在 75 °C 热床复查（热膨胀会改变平面）。

## 纸感判定

A4 纸置于喷嘴下方（Z=0），轻拉：

- **过紧**：纸张无法进入或明显夹紧 → 该角床面偏高
- **正常**：可顺利滑入，有均匀明确的阻尼感，拉动有阻力但不打皱 ← 目标状态
- **过松**：无接触 → 该角床面偏低

## 旋钮方向确认

每次先旋转 1/8 圈再判断方向：

- 纸张变紧 → 床面向喷嘴方向移动（拧紧方向）
- 纸张变松 → 床面远离喷嘴（拧松方向）

确认方向后全程沿用。第三轮起单次调整不应超过 1/16 圈。

## 调平顺序（190×190 坐标）

1. `G28`。移动至前左角 X20 Y20（抬 Z → 移动 → 分步下降），以此为基准手感。
2. 前右角 X170 Y20：调整旋钮至与基准一致。
3. 后右角 X170 Y170。
4. 后左角 X20 Y170。
5. 中心 X95 Y95：仅检查，不用角旋钮补偿。

四个角位相互影响，完整循环后首角会漂移。至少循环 3 轮，直至各角稳定在 1/16 圈以内。

## 中心与角位的关系

- 中心与角位手感一致 → 调平完成
- 中心明显偏松 → 玻璃/床面中部塌陷
- 中心明显偏紧 → 玻璃/床面中部隆起

中心与角位差异超过一张纸厚度时，禁止用角旋钮补偿。应重新铺放玻璃、检查玻璃下方异物或翻面。

## 测量精度说明

纸感仅用于定性比较。除非使用已知厚度塞尺或受控 Z 步进测量，否则不应将纸感转换为具体数值（如 0.03–0.05 mm）。

## 热床复查

冷床流程完成后，热床加热至 75 °C，静置 5 分钟待热稳定，再完整复查各角与中心。PETG 的实际打印平面为热态平面。

## 首层验收标准

- 线条轻微压扁、与相邻线融合、光泽均匀 → 正常
- 圆/珠状线条、有明显间隙、易脱落 → 喷嘴偏高
- 透明薄膜、脊线、刮擦声 → 喷嘴偏低
- 指甲可抠起的首层视为未修复
