# 流量上限（MVS）与提速档位

提速前须先核算流量需求。速度设置超过流量上限时，切片器会静默限速，实际路径并未提速，且长移动转角可能出现缺段。

## 本机已验证状态（2026-08）

| 来源 | 值 |
|---|---|
| Orca MVS（Generic PETG 235） | 10.5 mm³/s |
| Klipper `extruder.max_extrude_cross_section` | 50.0 |
| 喷嘴直径 | 0.400 mm |
| 层高 | 0.20 mm |
| 235 °C PETG 实测可持续流量 | 约 10.5–11.0 mm³/s（保守值） |

## 实测峰值流量（最终切片，1h50m，裙边 2mm，支撑 stl_2+stl_4）

- `inner_wall` 峰值 13.70 mm³/s，超出 MVS（Orca 静默限速）；均值 10.19
- `outer_wall` 峰值 10.85 mm³/s，临界超限
- `internal_solid_infill` 峰值 10.77 mm³/s，临界超限
- `sparse_infill` 峰值 10.48 mm³/s，在限内

内/外/实心填充峰值均超过 10.5，任务在 190/7350 运动限制下正常运行。此为"装饰性超速"模式：Orca 限速后打印正常，风险为跨转角填充行密度不均。

## 提速档位

- **档位 1（保守，约省 1–2 分钟）**：仅调整 top_surface 与 support_interface，流量需求在 MVS 内。
- **档位 2（适中，约省 4–5 分钟）**：增加稀疏/实心填充速度；MVS 需求上升约 8–10%，需目视观察。
- **档位 3（激进，本机不推荐）**：提高墙速与 Klipper max_accel；ATmega2560 步进率成为瓶颈。

## ATmega2560 步进率限制

16 微步、200 全步/转、40 mm 皮带齿距（X/Y）：190 mm/s 时每轴约 3,200 步/s。叠加 E 步（45 mm/s 回抽约 315 步/s），在 7350 mm/s² 加速度下 MCU 已接近单线程步进预算。继续提高加速度仅增加换向时的峰值步进率，不作为本机提速手段。

## 核算流程

1. 读取 Klipper 运行时 `extruder.max_extrude_cross_section` 与 Orca `mvs`/`mvs_enabled`。
2. 按特性计算需求：`mm³/s ≈ 线宽 × 层高 × 速度`。0.4 喷嘴、0.20 层高、132 mm/s 内壁 → 10.56 mm³/s。
3. 235–240 °C 的 0.4 喷嘴 PETG 可持续流量按约 10.5–11.0 mm³/s 计；超出须通过实测验证（更密填充、更小层、更高温度），而非仅调整切片参数。
4. 多特性同时超限（墙+填充+顶）时，首个缺料的长移动决定质量瓶颈，而非总 ETA。
